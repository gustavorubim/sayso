# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Be respectful and patient. Assume good intent, and remember that people here have different backgrounds and
  levels of experience.
- Critique code and ideas, not people.
- No harassment, insults, or discriminatory language, in issues, pull requests, discussions, or anywhere else the
  project is represented.

Maintainers may edit or remove contributions that break these rules, and may block people who repeatedly do so.

To report a problem, contact the maintainers privately through the
[repository owner's GitHub profile](https://github.com/gustavorubim). Reports are kept confidential.
